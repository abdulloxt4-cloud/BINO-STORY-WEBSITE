PROJECT Build a premium, award-style, scroll-driven one-page website for "BINO STROY", a construction company in Uzbekistan with 20 years of experience that also sells its own branded BINO roll waterproofing material. Phones: 93-123-02-02 and 97-333-04-02. Use the uploaded photo (black BINO rolls in front of an excavator on a site) as the main brand visual and as the texture reference for the rolls: black cylinders with a light paper band saying "BINO".
LANGUAGES (i18n) The site must be fully trilingual: Uzbek (Latin script), Russian and English. Add a language switcher "UZ | RU | EN" in the fixed top bar, visible on desktop and mobile. Default language: Uzbek. Detect the browser language on the first visit, save the choice in localStorage, switch instantly without a page reload, and update the <html lang> attribute. Use react-i18next with three JSON files (uz.json, ru.json, en.json) holding every visible string, including the layer descriptions, form labels, validation messages, chat texts, counters and button labels. Write natural, professional copy in all three languages (not literal machine translation), with no lorem ipsum. Make sure longer Russian words never break the layout.
TECH STACK Vite + React + TypeScript, Three.js via React Three Fiber and drei, GSAP + ScrollTrigger (scrub), Lenis smooth scroll, Tailwind CSS, react-i18next. Lazy-load heavy assets, keep 60fps, fully responsive. On mobile use lighter scroll-only animations and a 2.5D parallax fallback instead of heavy 3D. Respect prefers-reduced-motion. Clean, well-structured components, one component per scene.
GLOBAL DESIGN Dark charcoal background (#0d0d0d), warm sand/orange accent taken from the photo (#d9a441), soft glow behind objects, large bold sans-serif headlines (use a font with full Latin and Cyrillic support, such as Inter or Manrope) with thin subtitles, small monospace labels such as "OBJECT / 001 / 045-240", a fixed top bar with the logo, the language switcher and an INDEX menu, and a vertical scroll progress counter (01 / 07). Cinematic, minimal, expensive-looking. Smooth section transitions with pinned scenes.
